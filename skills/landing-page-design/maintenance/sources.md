# Landing Page Design sources

Maintenance-only.

## Upstream inspiration

- [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills) `skills/landing-page-design/SKILL.md` (Elaya), snapshot received 2026-10-30, MIT.
  - Kept: intake, page structure, layout types, conversion and copy rules, SEO/indexing rule, build order, the visual system (type, spacing, radius, backgrounds, hero, icons, motion, tagline reveal), states, ship requirements and checklist.
  - Changed for this repo: the description no longer claims every web UI task; precedence puts an existing brand or design system above the visual defaults; the "invent believable testimonials, logos and metrics" content-realism rule became proof honesty (real proof, or labelled placeholders and samples), matching `product-positioning` and `app-store-copy`; Chinese copy notes added.
  - Upstream itself credits [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (Leon Lin, MIT) for its content realism, motion and navigation ideas.
