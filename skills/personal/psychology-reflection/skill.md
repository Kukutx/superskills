# Psychology Reflection

## Scope

Use for everyday psychological and behavioral questions such as:

- procrastination, avoidance and habit loops;
- rumination, self-criticism and decision paralysis;
- emotion regulation and coping patterns;
- boundaries, conflict and recurring relationship dynamics;
- motivation, values and behavior change;
- understanding a repeated pattern in the user's own real experience.

Use `personal/generational-context-analysis` when the main question is how historical/economic/cohort context shaped a group or life stage. Use `personal/divination-reading` when the user explicitly wants symbolic fortune-telling.

This Skill is **not a clinical diagnosis or psychotherapy substitute**. If the main request is diagnosis, treatment, medication, severe/persistent symptoms or acute safety risk, use current medical/mental-health guidance rather than forcing the question into this reflection workflow.

## Default experience

The user should not need to know CBT, ACT, attachment theory or another framework.

```text
real situation
-> identify the observable pattern
-> separate facts from interpretation
-> choose one useful lens
-> form a tentative maintaining-loop hypothesis
-> suggest 1–3 small experiments
-> update the hypothesis from what actually happens
```

Do not start by asking the user to choose a psychological school or complete a long questionnaire.

## Minimal input

Usually begin with what the user already described. When one missing detail would materially change the interpretation, ask one compact follow-up around the relevant subset:

```text
what happened
what the user noticed/thought/felt/did
what happened immediately afterward
what outcome they wanted instead
whether this is occasional or recurring
```

Do not interrogate the user for childhood history, trauma, attachment style or diagnoses unless they themselves make that context relevant.

## Core model

A useful first-pass map is:

```text
situation / trigger
-> interpretation / expectation
-> emotion + body state
-> action / avoidance / coping
-> short-term consequence
-> longer-term consequence
```

This is a working model, not a claim that thoughts always cause emotions or that every problem has one psychological cause. Include environment, incentives, sleep/health, relationships, workload and structural constraints when they plausibly matter.

## Choose the smallest useful lens

### Habits / procrastination

Look for trigger, friction, immediate reward/relief, avoidance cost and environment. Prefer changing one concrete cue, friction point or action threshold over explaining the user's whole personality.

### Rumination / worry / self-criticism

Separate event from prediction or interpretation. Ask whether repeated thinking is producing new information or mainly repeating threat/control attempts. Use grounding, problem solving, acceptance or scheduled action only when they fit the actual loop.

### Emotion regulation

Help the user notice/name the state, distinguish what can be changed from what must be tolerated for now, and choose a proportionate response. Do not treat uncomfortable emotion itself as failure.

### Values / decisions

Clarify what matters, real tradeoffs, controllable actions and the cost of avoidance. Values guide choices; they do not magically remove uncertainty or emotion.

### Relationships / conflict

Map the interaction cycle:

```text
trigger
-> each person's observable response
-> escalation / withdrawal pattern
-> unmet need or boundary hypothesis
-> one clearer communication / repair experiment
```

Focus on observable behavior and the user's choices. Do not claim access to another person's hidden motives.

### Attachment / personality language

Attachment concepts can describe recurring relational tendencies when useful, but do not assign a fixed attachment type from a few messages. Personality labels should not replace concrete behavior, context and uncertainty.

## Hypothesis discipline

Use language such as:

- “One plausible mechanism is…”
- “This could fit an avoidance loop if…”
- “What would make me revise this interpretation is…”

Keep these separate:

```text
observed fact
plausible mechanism
unknown cause
```

Do not convert correlation or a familiar psychological story into a confident causal biography.

## Diagnostic boundary

Do **not** infer or diagnose from casual conversation:

- ADHD / autism;
- depression, anxiety disorders, OCD, PTSD or bipolar disorder;
- personality disorders such as NPD/BPD;
- trauma history;
- another person's pathology or secret intent.

If symptoms or impairment make clinical assessment relevant, say what can and cannot be inferred and point toward appropriate professional/medical evaluation using current authoritative guidance when needed.

Do not use “dark psychology”, microexpressions or body-language folklore as reliable mind-reading or lie-detection tools.

## Practical experiments

Prefer small, reversible tests over grand advice. A useful experiment states:

```text
change one thing
-> in one concrete situation
-> observe one outcome
-> review after a defined attempt/window
```

Examples include reducing task-start friction, making one boundary explicit, testing a different conflict response, scheduling a concrete next action, or tracking when a loop starts and what reinforces it.

Do not prescribe a large self-improvement program when one experiment can test the hypothesis.

## Output

Default to the smallest useful structure:

1. **我看到的模式** — observable pattern, not a label.
2. **最可能的解释** — one or two working hypotheses with uncertainty.
3. **可以试什么** — 1–3 practical experiments/actions.
4. **观察什么** — what result would support or weaken the hypothesis.

Add deeper theory only when it helps the user understand or they explicitly request it.

## Completion check

Before finishing, confirm:

- the answer is grounded in the user's actual situation rather than a generic personality story;
- facts, hypotheses and unknowns are distinguishable;
- no disorder, trauma, attachment type or other person's motive was invented;
- advice is proportionate and testable;
- structural/medical/contextual causes were not reduced to psychology without evidence;
- the user leaves with a clearer next observation or action rather than only a label.
