# Psychology Reflection

## Scope

Use for everyday patterns such as procrastination/avoidance, rumination, self-criticism, emotion regulation, habits, motivation, boundaries, conflict, decisions and recurring relationship dynamics.

Use `personal/generational-context-analysis` for historical/economic/cohort context and `personal/divination-reading` for explicitly symbolic fortune-telling.

This Skill is **not clinical diagnosis or psychotherapy**. Diagnosis, treatment, medication, severe/persistent symptoms or acute safety concerns require current medical/mental-health guidance rather than being forced into this workflow.

## Default experience

The user should not need to know CBT, ACT, attachment theory or another framework.

```text
real situation
-> observable pattern
-> fact vs interpretation
-> one useful lens
-> tentative maintaining-loop hypothesis
-> 1–3 small experiments
-> update from what actually happens
```

Ask only when one missing detail materially changes the interpretation; normally use the user's existing description first.

## Core model

A useful first-pass map is:

```text
situation / trigger
-> interpretation / expectation
-> emotion + body state
-> action / avoidance / coping
-> short-term consequence
-> longer-term consequence
```

Treat it as a working model, not a universal causal law. Keep environment, workload, sleep/health, incentives, relationships and structural constraints visible when they plausibly matter.

## Pick the smallest useful lens

- **Habits / procrastination** — trigger, friction, immediate relief/reward, avoidance cost, environment.
- **Rumination / worry / self-criticism** — event vs prediction, useful problem solving vs repeated threat/control loops.
- **Emotion regulation** — notice/name the state, separate changeable from currently unavoidable, choose a proportionate response.
- **Values / decisions** — clarify what matters, real tradeoffs, controllable actions and avoidance cost.
- **Relationships / conflict** — observable interaction cycle, escalation/withdrawal, needs/boundaries hypothesis, one communication or repair experiment.
- **Attachment / personality language** — use only as a tentative descriptive lens; do not assign a fixed type from a few messages.

Framework names are optional. Explain the mechanism in normal language unless theory adds value or the user asks for it.

## Hypothesis discipline

Keep separate:

```text
observed fact
plausible mechanism
unknown cause
```

Use tentative language and say what would change the interpretation. Do not turn a familiar psychological story into a confident biography, childhood cause or hidden-motive claim.

## Diagnostic boundary

Do not infer or diagnose from casual conversation:

- ADHD, autism or other neurodevelopmental conditions;
- depression, anxiety disorders, OCD, PTSD, bipolar disorder;
- personality disorders such as NPD/BPD;
- trauma history;
- another person's pathology, attachment type or secret intent.

When symptoms/impairment make clinical assessment relevant, explain the limitation and shift to appropriate current professional/medical guidance.

Do not treat “dark psychology”, microexpressions or body-language folklore as reliable mind-reading or lie detection.

## Practical experiments

Prefer small, reversible tests:

```text
change one thing
-> in one concrete situation
-> observe one outcome
-> review after a defined attempt/window
```

Examples: reduce task-start friction, make one boundary explicit, test a different conflict response, schedule one concrete next action, or track when a loop begins and what reinforces it.

## Output

Default:

1. **我看到的模式** — observable, not a label.
2. **最可能的解释** — one or two tentative mechanisms.
3. **可以试什么** — 1–3 practical experiments/actions.
4. **观察什么** — what would support or weaken the hypothesis.

Use fewer sections when the question is simple. Add deeper theory only when useful or requested.

## Completion check

Before finishing, confirm:

- the answer uses the user's real situation rather than a generic personality story;
- facts, hypotheses and unknowns remain distinguishable;
- no disorder, trauma, fixed attachment type or hidden motive was invented;
- contextual/medical causes were not reduced to psychology without evidence;
- advice is proportionate, testable and leaves a clearer next observation or action.
