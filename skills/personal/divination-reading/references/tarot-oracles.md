# Tarot and Oracle Reference

Use for Tarot and comparable card-based symbolic readings.

## Tarot baseline

A standard modern Tarot deck has 78 cards: 22 Major Arcana (21 trumps plus the Fool) and 56 Minor Arcana across four suits. Deck traditions and imagery vary, so interpret the actual deck when known rather than assuming every card system uses identical symbolism.

## Start with the question

Prefer a question that can produce reflection or choices:

```text
What am I overlooking in this situation?
What dynamic should I understand before making this decision?
What is helping / blocking / worth trying next?
```

Avoid treating cards as a factual detector for hidden crimes, diagnoses, pregnancy, investment returns or another claim that requires evidence.

## Choose the smallest useful spread

| Need | Suggested shape |
| --- | --- |
| one theme / daily reflection | 1 card |
| situation / challenge / response | 3 cards |
| two options with tradeoffs | 4–5 cards |
| layered situation with several actors/times | custom 5–7 cards |
| broad traditional overview | larger spread only when the user wants it |

Do not default to a large Celtic-Cross-style reading when three cards answer the question.

## Draw integrity

Use one of three honest modes:

1. **User/deck draw** — user provides the cards.
2. **Tool draw** — a real card/randomization tool provides the cards.
3. **Simulated symbolic draw** — the model selects cards for the reading; label it clearly as simulated rather than claiming physical randomness.

Do not redraw until a preferred answer appears. A clarification card should answer a specific unresolved point, not erase an inconvenient card.

## Reversals

Reversed cards are optional. State the convention before interpreting:

- upright-only;
- upright + reversed;
- directional/elemental dignity or another deck-specific rule.

Do not switch reversal policy after seeing the draw.

## Interpretation order

For each position:

```text
position/question role
-> card image/archetype
-> relevant traditional meaning
-> interaction with neighboring cards
-> concrete reflection for this question
```

Then synthesize the spread as a whole. Avoid giving 10 unrelated keyword meanings for every card.

Useful synthesis asks:

- What theme repeats?
- Where is tension or contradiction?
- Which card describes context versus choice versus likely consequence?
- What action remains under the user's control?

## Predictive language

Prefer:

- “This spread emphasizes…”
- “A traditional reading would suggest…”
- “If this pattern describes the situation, the practical implication is…”

Avoid:

- “This proves…”
- “This person definitely…”
- “You will certainly…”

When timing is requested, use broad symbolic windows only if the chosen reading tradition supports them and make the uncertainty explicit.

## Other card/oracle systems

Lenormand, oracle decks, playing-card cartomancy and runic/oracle systems have their own grammar. If the user specifies one, follow that system instead of forcing Tarot's Major/Minor Arcana meanings onto it.

Do not add a permanent reference for every oracle deck. Use deck-specific instructions only when the actual task requires them.

## Reading output

A focused Tarot answer usually needs only:

1. question + spread;
2. cards drawn and draw mode;
3. position-by-position interpretation;
4. overall synthesis;
5. practical reflection / next step;
6. one uncertainty or alternative reading when genuinely present.
