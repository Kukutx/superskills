# 六种脚本母版

旁白讲故事，画面只给关键词、数字和出处。每拍写成口语短句，一句不超过 22 字。拍号（B01、B02…）就是旁白分段。

## A · 猜谜概念片

**适合**：一个抽象概念（熵、本福特定律、贝叶斯、纳什均衡）。惯例 3:30–4:30。

| 拍 | 做什么 | 画面 |
| --- | --- | --- |
| B01 冷开场 | 一道人人能接的直觉题，再给一个猜不到的版本；先不出标题 | 大问题卡 |
| B02 点题 | 一句话说出这个反差就是本期概念 | 系列片头 + 片名 |
| B03–B04 | 一个能玩的小游戏把概念量化；谁、哪年命名了它 | 计数器、柱状、人物剪影 |
| B05–B06 | 两个熟悉的例子（一个接近 0、一个很大）；公式只出现一次，配一句大白话 | 关键词、公式淡入 |
| B07–B08 | 让观众亲身体验一次（错觉、乱序字）；金句收段 | 互动画面 |
| B09–B10 | 尺度拉到宇宙或历史；被当成噪声的东西恰恰是最大发现 | 全片王炸镜头 |
| B11 | 概念的边界：它解释不了什么 | 左右对比 |
| B12 | 落回观众今天的手机或工作 | 生活场景 |
| B13 回环 | 重现 B01，这次让观众来填 | 与 B01 同构图 |

## B · 两难选择片

**适合**：历史事件、博弈论、心理学实验。系列化时固定约 2:55。

| 拍 | 做什么 | 画面 |
| --- | --- | --- |
| B01 | 一句话讲完离奇事实，结果放在最后几个字 | 全屏场景 + 原文脚注 |
| B02 | 「换你：……你，……不……？」 | 大问题卡 |
| B03 | 系列片头 | 片名 |
| B04 前情 | 一个具体细节让人物立起来；一句古今连接 | 场景 + 竖排原文 |
| B05 经过 | 时间、地点、动作，数字一步步上去；史书分歧两说并列 | 地图扩散 + 计数 |
| B06 等待 | 倒计时；普通人这段时间在做什么 | 动态镜头 |
| B07 揭晓 | 结果，停一下 | 关键词砸入 + 音效 |
| B08 反转 | 后人怎么拆穿，原话上屏 | 竖排原文 |
| B09 对照组 | 另一个时代照做，结果完全不同 | 同一张地图对比 |
| B10 回问 | 再问一遍 B02，给两个按钮 | 选择按钮 |

## C · 痛点原理片

**适合**：日常困扰 × 一个冷门原理。2:00–2:30。

日常反常 → 「到底是谁偷走了……」→ 冷门原理（人名 + 年份）→ 一个贯穿道具（电量条、小黑板）→ 代入观众的一个下午（每条挂出处）→ 3 秒能做的解法 → 第二个反常 → 治愈收尾。道具每拍都出现并变形，结尾回升。

## D · 一条主线片

**适合**：学科体系、技术史、一件器物或一个家族的身世。约 3:00。

N 个看似无关的碎片 → 「其实有一条线」→ 一条发光的线依次穿过 5–7 个节点，每个节点一个时代画面 → 线收成网或树 → 问观众哪两个联系最紧。首尾用同一个画面回环。

## E · 闯关片

**适合**：考试题型、方法论、流程。4–6 分钟。

冒险地图 → 每关：题干 → 陷阱选项 → 正解 → 掉落一张秘籍卡 → 最终综合题 → 一屏秘籍总表（这一屏是被收藏的理由）。

## F · 六面轮转片

**适合**：哲学流派、观点对比、「一件事的六种答法」。45–60 秒。

一个大问题 → 「有人给过六种答案」→ 每种 5–7 秒：人名 · 书名 · 年份 + 一句原话 → 「没有一面是纯色的」→ 「你转到哪一面了？」主道具是一个每转一面换一种颜色的立方体。

## 所有母版共用

1. 前 3 秒让观众参与：猜、选或认出一个日常场景。不先上标题，不自我介绍。
2. 钩子讲完再出片名。
3. 一个主道具贯穿全片；概念变了道具变形，不换道具。
4. 每个事实挂出处；示意画面标明；分歧两说并列。
5. 画面字只放关键词（≤8 字）、数字和出处。
6. 每章一句能截图的金句。
7. 结尾回扣开头，把一个能用一个词回答的问题交给观众。
