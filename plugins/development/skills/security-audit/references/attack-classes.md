# Attack classes to cover

Web and API: authentication and session handling, authorization and cross-tenant
isolation, injection (SQL, command, template, expression), cross-site scripting
(stored and reflected), CSRF and cross-origin trust, deserialization, path
traversal and file handling, SSRF, open redirects, rate limiting and resource
exhaustion. Data: encryption at rest and in transit, secret handling, PII and
tenant isolation, backup and retention. Platform: supply chain and dependency
integrity, build and release signing, configuration and deployment defaults,
logging and audit trails, client-side trust (mobile, desktop, IPC), protocols
and messaging, memory safety, and AI/LLM-specific surfaces (prompt injection
through untrusted input, tool-call confusion, data exfiltration via model output).
