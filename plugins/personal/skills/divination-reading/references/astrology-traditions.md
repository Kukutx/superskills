# Astrology Traditions Reference

Use for Jyotiṣa / Indian astrology and optional Western astrology. These traditions use astronomical chart inputs but their interpretive claims remain traditional rather than empirically established forecasting.

## Jyotiṣa / Indian astrology

Prefer the term **Jyotiṣa / Indian astrology** when discussing the broader tradition. “Vedic astrology” is common in popular usage but can imply a single uniform ancient system where historical and modern schools are more complex.

Useful branches include:

- **jātaka** — natal astrology;
- **praśna** — horary/interrogational astrology for a specific question;
- **muhūrta** — electional timing;
- additional predictive/divisional/dasha techniques depending on school.

### Exact chart gate

A reliable natal chart needs:

```text
birth date
time + precision
birth place / coordinates
historical timezone / DST
ephemeris
zodiac/ayanāṁśa convention
```

Indian practice commonly uses a sidereal zodiac, but ayanāṁśa choices differ. Do not silently assume one if exact sign/nakṣatra boundaries matter.

If a charting tool is unavailable, ask for a precomputed chart or placements instead of guessing lagna, planets, nakṣatras, divisional charts or dashā periods.

### Interpretation order

Keep the reading proportional to the question:

1. lagna/ascendant and chart ruler under the selected school;
2. relevant houses and their lords;
3. planets, sign/house condition and major aspects/conjunctions;
4. Moon/nakṣatra where materially relevant;
5. divisional charts only when the question actually needs them and the birth time is precise enough;
6. dashā/transit timing only from a verified chart/calculation.

Do not use one isolated yoga or “dosha” as a deterministic verdict. Explain how the factor interacts with the rest of the chart and whether different schools treat it differently.

### Praśna

Use for one well-formed question when a horary chart can be calculated from a defined question time/place. State what moment/location defines the chart. Do not retroactively choose a more convenient time after seeing the outcome.

### Muhūrta

Use only when the user actually wants electional timing. Treat it as a traditional symbolic selection framework, not a guarantee that an event will succeed.

## Western astrology

Use when explicitly requested or when the user prefers a Western natal/transit framework.

Exact work should state:

```text
ephemeris/source
tropical or sidereal zodiac
house system when houses matter
birth timezone/place accuracy
```

Tropical astrology is common in modern Western practice, but other approaches exist. Do not mix tropical positions, sidereal Jyotiṣa placements and house conventions in one chart without clearly separating them.

### Natal / transit discipline

For a natal reading, start with a small hierarchy rather than every minor aspect:

- luminaries and ascendant when verified;
- chart ruler / angular emphasis;
- relevant houses and planets;
- major aspects/patterns;
- transits/progressions only when timing is requested.

Exact transits require a current ephemeris. Do not estimate planetary positions from memory.

## Cross-tradition boundary

Jyotiṣa and Western astrology may use some shared astronomical bodies and zodiac vocabulary, but they are **not interchangeable calculation systems**.

If the user wants comparison:

1. calculate each chart under its own conventions;
2. interpret each internally first;
3. compare themes only after both readings are complete;
4. do not treat agreement as empirical proof or disagreement as a calculation error by default.

## High-stakes restraint

Do not use either tradition to assert:

- a medical diagnosis or death prediction;
- legal guilt/innocence;
- guaranteed investment performance;
- certainty about another person's secret behavior;
- unavoidable marriage/fertility outcomes.

Translate symbols into reflection, timing hypotheses and choices the user can evaluate against real evidence.
